# Gift Quest Site

Небольшой статический сайт-квест для сюрприза на день рождения.

## Как это работает

1. На старте открывается экран с 5 загадками.
2. Девушка ищет карточки по квартире.
3. Карточки складываются в картинку с секретным словом.
4. После ввода правильного слова открывается остальной сайт.

## Что менять

Основной текст лежит в `script.js` внутри объекта `siteContent`:

- `girlName` - имя
- `relationshipStart` - дата начала отношений `YYYY-MM-DD`
- `unlockAnswer` - секретное слово с карточек
- `riddles` - 5 подсказок
- `heroTitle` и `heroText` - главный экран после разблокировки
- `wishText` - короткое пожелание
- `reasons` - список теплых фраз
- `letterLines` - текст письма
- `foodOptions` - варианты еды
- `surpriseTitle` и `surpriseText` - финальная подсказка

Сейчас секретное слово: `я тебя люблю`.
На карточках должно получиться то же самое.

## Как открыть локально

Открой `index.html` в браузере.

## GitHub Pages

Залей файлы в корень репозитория и включи Pages на ветке `main`.
